## Advertencia sobre el presupuesto

Con un presupuesto de partida de $50, el extremo alto de este estimado **podría excederse**. Para mantenerse dentro:

1. Compre primero lo indispensable: ESP32, DS18B20, TDS, turbidez y LCD.
2. Reutilice vasos, bandejas, cartón y cajas para la maqueta.
3. Compare precios de módulos genéricos entre varias tiendas, verificando que traigan la placa convertidora.
4. Evite el sensor de pH y cualquier mejora hasta que el sistema base funcione.
