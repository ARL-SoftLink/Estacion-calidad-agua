# Datos

Guarde aquí los CSV de **muestras reales etiquetadas** exportados desde el panel (`/api/datos.csv`).

Formato: `instante,temperatura,tds,turbidez_mv,etiqueta,simulada`

- No suba datos simulados (`simulada = true`) como si fueran mediciones.
- Anote junto a cada archivo la fecha, las condiciones y las cantidades usadas en cada muestra.
